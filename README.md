# Pão & Afeto — Padaria & Cafeteria

Modelo responsivo para padaria, cafeteria ou confeitaria. Inclui vitrine de produtos, filtros, sacola de pedidos, encomendas e integração com WhatsApp.

## Personalize antes de usar

- Altere o telefone `5511999999999` nos arquivos `index.html` e `script.js`.
- Substitua produtos, preços, imagens, endereço e horários.
- Abra `index.html` no navegador para visualizar; não é necessário instalar dependências.
